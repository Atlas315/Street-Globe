# Street-Globe 🌍

Interactive 3D globe exploring streetwear culture, sustainable fashion, and authentic product guidance.

一个交互式3D地球应用，探索全球潮牌文化、可持续时尚与正品倡导。

---

## ✨ Core Features / 核心功能

### 1. 3D Interactive Globe / 3D地球交互
- Rotatable, zoomable 3D globe
- Click countries/cities to view local streetwear brand info
- Hotspot markers for brands and vintage stores

### 2. Streetwear Brand Database / 潮牌信息库
- Brands organized by region (Japan, US, Europe, China, etc.)
- Each brand: history, design style, signature products, official links
- Sustainability rating for each brand

### 3. Sustainable Fashion Module / 可持续时尚模块
- **Brand Sustainability Rating**: material transparency, labor standards, carbon reduction, eco-certifications
- **Carbon Footprint Calculator**: estimate full-lifecycle carbon emissions of any garment
- **Fabric Eco Database**: environmental impact ratings for common fabrics (cotton, polyester, nylon, wool, linen, Tencel, etc.)
- **Carbon Footprint Ranking**: brand-level carbon footprint visualization

### 4. Vintage Store Map / 古着店地图
- Global vintage store locations on the 3D globe
- Store info: address, hours, style specialty, price range
- Filter by region and style

### 5. Upcycling Inspiration / 旧衣改造灵感库
- Before/after upcycling case studies
- Tutorials organized by difficulty and type (T-shirt, jeans, accessories)
- Community uploads (v2.0)

### 6. Authenticity Guide / 正品倡导模块
- **Authentication Guides**: side-by-side real vs fake comparisons for popular brands (BAPE, Supreme, Stüssy, etc.)
- **Authorized Retailer Map**: official stores, reputable boutiques, trusted second-hand platforms
- **Authenticity Philosophy**: why buying authentic = supporting sustainability (quality lasts longer, fakes create waste)
- **Community Authentication Help** (v2.0)

## 🛠 Tech Stack / 技术栈

| Layer | Technology | Notes |
|-------|-----------|-------|

| Backend | None (static) | Content stored in JSON files |

| Responsive | Mobile-first | Primary users on mobile, desktop has enhanced interactions |

## 🎯 Philosophy / 核心理念

**Streetwear + Sustainability + Authenticity** — three pillars, one platform.

We believe in **"Buy less, buy better, wear longer"** (买少、买好、穿久):
- Authentic products last years → less consumption → more sustainable
- Fakes fall apart quickly → create waste → harm the environment
- Upcycling gives old clothes a second life
